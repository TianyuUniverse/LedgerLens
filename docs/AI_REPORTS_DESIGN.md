# 成长图鉴与 AI 向导

本轮将 AI 接入“观察指标 → 核对依据 → 建议行动 → 游戏陪伴 → 复盘故事”。AI 负责中文理解、建议与叙事；Python 负责日期范围、金额、指标、来源验证和保存边界。

## 数据与图表

`ledger/reports.py` 在 SQLite 一致性读事务中取账单、预算、目标、储蓄记录、奖励和心得快照。以快照、周期与截至日期的哈希缓存报告。周从星期一开始；跨月周预算按每天所属月份的天数折算。当前月份与上月相同已过天数比较；历史完整月份按全月比较。未来日期和未来储蓄不进入本期指标。无导入账单并不证明实际没有消费。

`static/reports.js` 以原生 SVG 绘制可缩放折线图、环形图、目标储蓄曲线和雷达图。来源点、分类图例与事实标签连接到原账单。缺少数据的雷达维度显示空缺，不按零分连接多边形。图表支持下载 SVG；有数字的图表由程序绘制。

| 维度 | 计算口径 |
| --- | --- |
| 分类清晰 | 本期已确认分类笔数 / 本期导入笔数，不表示真实账单完整率 |
| 预算节奏 | 已设置类别预算与对应支出的比值，限制至百分制后取平均；预算按日历天折算 |
| 收支缓冲 | 本期结余率 / 30% 后限制至百分制；无收入记录不评分 |
| 目标推进 | 截至本期末各目标累计完成比例的平均值，含归档目标；来自个人记录 |
| 行动习惯 | 有经验的不同日期 / 参考天数，周三天、月十二天；无行动记录不评分 |
| 复盘习惯 | 不同日期的心得数 / 参考次数，周一次、月四次；无行动及复盘数据不评分 |

这些参考值是设计假设，A–E 是本项目的展示标尺。没有验证其与真实财务能力、信用、理财收益或长期参与度的关系。

## AI 输出与边界

用户勾选同意并点击生成后，模型只收到周期、汇总事实、指标及公式、允许的行动类型。不会收到逐笔商户、交易对方或备注。模型输出结构化 JSON：标题、事实引用的解读、行动卡、四格场景和对白。程序检查引用存在、长度和场景顺序，拒绝未知动作、数字金额和非法结构。页面上的金额事实来自程序；AI 解读依然可能存在语义偏差，应由用户结合引用核对，不能把结构检查称为完全消除幻觉。

向导任务只能前往已有的审核、预算、储蓄方案、目标或复盘功能。生成报告、阅读建议、点击卡片都不会直接授予经验或修改账本。完成具体人工操作后沿用既有服务端奖励规则。

四格图使用 `static/images/comic-flat.png` 预制插画。每期的分镜、引用和对白由运行时模型生成；未启用或失败时明确显示本地模板。没有声称每次调用 DeepSeek 都会画一套新图。图片来源与最终提示词见 [素材记录](ART_ASSETS.md)。

成功的 AI 报告按快照持久缓存，重新打开可直接显示。数据变化后重新计算本地报告，云端内容需重新点击生成。失败不冒充成功缓存，用户可重试。软件关闭时没有定时服务，不产生后台模型费用。

## 一句话记账

`ledger/entry.py` 提取一笔明确金额和今天／昨天／明确日期；多金额、负数、超精度与未来日期要求用户修正。可选 AI 只建议用途、收支类型与描述，不能改变程序提取的金额和日期。前端填入可编辑表单，用户确认后调用保存接口。人工确认优先，不会被记忆静默覆盖；保存复用导入校验、原始身份重复检查与审计事务。

## 验证与复现

- `python -X utf8 -m unittest discover -v`：本轮总计 129 项，新增 22 项覆盖金额、跨年／闰月／跨月周、当前周期比较、缺失数据、历史目标、缓存、同意、异常模型与记账草稿。
- `node scripts/reports_browser_check.cjs`：隔离合成账本，验证 UI、图表交互、导出与手机布局。使用 Playwright 和 Edge；`FINANCE_PYTHON` 可指定解释器。
- `python -m scripts.live_reports_check`：主动运行会调用已配置模型三次，仅使用合成账单。本轮两份报告与一份草稿成功，账本与经验不变。这不是独立模型准确率实验。

使用的官方接口与 CI 参考：[DeepSeek JSON Output](https://api-docs.deepseek.com/guides/json_mode/)、[GitHub Python CI](https://docs.github.com/en/actions/tutorials/build-and-test-code/python)。
