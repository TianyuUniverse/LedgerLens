# 使用说明

> 当前版本：游戏展示已撤下，储蓄目标保留。微信原始 `.xlsx` 可直接导入，不必转 CSV。请先阅读[当前导入与分类记忆说明](WECHAT_IMPORT_AND_MEMORY.md)。下文的旧游戏步骤仅保留为历史记录。


软件界面现已统一为简体中文，包括菜单、分类、提示、分类记忆、方案、问答和操作记录。下载模板与导出表头为中文；英文与中文表头均可导入。原有账单内容保留。

双击根目录 `Start_LedgerLens.bat`，在浏览器打开 http://127.0.0.1:8765。也可运行 `python app.py`。需要 Python 3.10+，应用本身只使用标准库。本机已配置 DeepSeek；密钥只在私有文件 `data/provider.json`，不在 Git 和项目压缩包里。

点击 **加载示例账单** 加载 30 条合成记录。重复加载会跳过重复项，不清空已有数据。自己的账本在 `data/ledger.sqlite`。需要独立演示环境时，运行 `python app.py --port 8768 --db data/new-demo.sqlite`。

## 历史版本：目标冒险（当前已撤下）

1. 在首页点击 **开启新目标**，填写愿望、目标金额、已有储蓄和可选日期。已有金额决定起点，不赠送里程碑经验。
2. 点击 **记录储蓄进展**，填写已确认留出的存款；需要动用时选“从目标取回”。这些是你个人确认的目标记录，不自动变成账本支出，也不等于已核验的银行余额。
3. 达到 25%、50%、75%、100% 时，营火、树屋、观景台和目标旗帜依次点亮。
4. 通过每日小任务整理新账单、确认模糊用途、保存一条复盘心得。创建分类记忆、审核保存方案还能获得成长徽章。
5. 达到第 2 级解锁 **海岛灯塔**，第 4 级解锁 **星际航线**。点击主题即可切换。任务经验、等级和徽章会持久保存。
6. 每周在三个不同日期完成财务行动，可获得额外经验。中断不扣分，取回储蓄也不扣经验。
7. 同时最多进行三个目标；可以归档并重新启程，历史记录和已获得经验都会保留。目标金额创建后固定。

重复导入不会完成新账单任务；同一天修改复盘不会重复领奖；取回后再存入、刷新页面、重复发送同一笔操作都不会重复增加奖励。每日全部目标的里程碑经验合计最多 200 点。奖励规则和流水可展开 **旅程记录与奖励规则** 查看。

目标进度按个人储蓄记录计算，AI 测算结果不会直接当作已完成的存款。日期和每日任务以北京时间计算。

## 分类记忆演示

1. 找到 **分类记忆**，点击 **第一步：加载记忆示例**。
2. 对学校伙食费点击 **确认消费用途**：Kind 选 Expense，Category 选 Food，填写实际用途。
3. 保留收款方、描述及备注中的伙食费等匹配条件，勾选 **批准符合条件的后续账单自动分类** 后确认。
4. 对舍友电费和空调费同样确认，改为 Expense / Utilities，并批准匹配条件复用。
5. 点击 **第二步：导入后续账单**。两笔符合用途条件的新账单自动修正。付给同一学校的学费、给同一舍友的其他转账需要再确认。
6. 在记忆列表可编辑、停用、启用或删除。已有账单保留当时的分类和记忆版本，不会被后台改写。

示例全部是合成数据。首次用途不清的账单会进入待审核。系统保留来源的原始收支类型、分类、备注和收款方。自动复用按用户批准的条件匹配，不是只看收款方。语义相似但条件不够的模型建议仍需确认。若备注和描述都没有可区分的用途，不能仅凭收款方批准自动分类。

## 多轮问答和储蓄方案

在 **财务助手** 勾选 **本次对话启用 AI 分析** 后才会让 DeepSeek 理解问题并选择工具。未勾选时是明确标注的本地确定性模式。

- 问“九月为什么比八月花得多？”：显示两个月金额、分类变化和来源账单。
- 追问“去掉 #26”：用实际支出记录的编号替换 26。只从本次分析排除，不删除账单。描述匹配多笔时先选具体编号。“取消排除”可恢复。
- 问“我想六个月存6000，房租不能减，娱乐每月至少留200。”再问“我不想减少餐饮。”：保留原目标和已有限制，重新计算方案。
- 点 **查看预算并选择方案** 展开预算，选择 **选择并保存此方案** 才保存。达不到目标会显示差额，不会降低最低预算。账单变化后须重新生成预览才能保存。
- **新建对话** 开始新的比较和约束上下文。同一对话编号的上下文会保存在本地数据库。

**储蓄方案** 也有表单入口，无需模型。方案采用最近三个日历月均值、明确列出的减支上限、固定类别与最低预算。缺失月份按零计算，这是情景假设，不代表未来保证。可行空间不足时，三种策略可能得到同一份预算。

**消费复盘** 查看月度变化、跨月重复收款方及 20 元以下（含 20 元）的小额消费，附账单依据。重复交易不等于无用订阅，账单变化也不能单独说明消费动机。

启用 AI 的聊天会发送问题、最近对话和所查工具结果，可能含金额和账单内容。点击 **获取分类建议** 会发送所选记录的描述、收款方、备注、原始标签和相关确认记忆。演示请使用合成样例。金额由 Python 按“分”计算，模型没有改账或任意 SQL 工具。服务失败会标注回退来源。
